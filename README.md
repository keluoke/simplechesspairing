# ♟️ SimpleChessParing - 极简国际象棋俱乐部瑞士制编排系统

专门针对**国际象棋俱乐部内部积分赛、周赛、快棋赛与训练赛**定制研发的微信极简风格纯前端 Web 编排软件。无需联网即可离线运行，即开即用；亦可零成本一键部署至 **Cloudflare Pages**，随时随地在手机或电脑上完成配对与成绩录入。

---

## ✨ 核心亮点

1. **微信极简风格与多组别/多赛事自由管理**：
   - **名称与定位**：SimpleChessParing，采用微信极简绿色风格 UI，高清晰度，操作零学习成本。
   - **默认“俱乐部积分赛”**：默认单组“俱乐部积分赛”，新比赛名单默认留空；支持直接从 Excel 或微信复制整列粘贴，自动过滤序号（如 `1. 张三`）、自动去除同名重复、支持附带等级分（如 `张三 1600`）。
   - **自定义组别与多赛事并行**：点击 **“➕ 新建组”** 任意创建多组赛事（如 *少儿组*、*精英组*、*公开组*），各组独立存储、编排与计分。
   - 保留一键载入 8 人与 20 人示例名单的快捷模版。
2. **URL 路由带参深层分享与跨设备数据快照传输**：
   - **URL 深度链接**：地址栏实时保持同步（如 `?group=men&round=3&tab=standings`），支持直接跳转至指定组别、指定轮次或排行榜。
   - **跨设备无损快照分享（解决换浏览器无数据痛点）**：通过“复制分享”生成携带压缩数据快照的 URL（`#d=...`）。**发到微信群后，家长和棋手用任何手机或新浏览器点开，瞬间还原最新排阵与积分，无需裁判在线，零服务器成本，换浏览器绝不丢数据**；其他裁判亦可点击“保存并接管比赛”。
   - **Magic Link 快速开赛**：支持通过链接传参直接开赛，如 `?title=秋季校际赛&players=张三,李四,王五,赵六`。
3. **专业对阵与成绩签单导出 (满足比赛签字规范)**：
   - **支持每一轮对阵签单导出与打印**（无论是当前轮次还是历史第 1、2、3... 轮）。
   - 表格中间设有醒目的**赛果比分填报区**，右侧设有**白方签字、黑方签字与裁判/复核签字栏**。
   - 支持**手写空白签单模式**（供赛前张贴、发放给棋手手写成绩并签字）和**官方成绩存档模式**（含已录比分）。
   - 一键直接**打印 / 另存为 PDF**，或一键导出为 **Excel / CSV 表格**（带 UTF-8 BOM，Excel 打开绝无乱码）。
4. **中途允许 0 分选手入场**：比赛进行到任意轮次（如第 2 轮、第 3 轮），迟到或新到的选手可随时以 **0 分**初始积分入场，自动参与后续轮次编排配对。
5. **临时请假/休战控制**：选手临时有事需要请假（如休战一轮），一键设置为【本轮请假】，系统自动将其排除配对，已有积分与破同分完整保留；选手回归时一键恢复参赛即可继续按积分配对。
6. **标准瑞士制配对逻辑**：
   - **同分群优先**：高积分对战高积分，低积分对战低积分。
   - **绝不重复交手**：严格遵循同一赛事中两名选手不重复对弈原则。
   - **黑白棋交替与平衡**：严格控制每位棋手的黑白棋数量，规避连续3盘同色，自动优先平衡执白与执黑次数。
   - **奇数轮空自动处理**：参赛人数为奇数时（如女子组7人），自动安排最低分且尚未获得过轮空的棋手轮空获胜（+1.0 分），确保轮空不重复。
7. **实时积分榜与破同分**：
   - 每一台对局结果点击（`1 - 0`、`½ - ½`、`0 - 1`）即时生效。
   - 自动计算并展示：**总积分**、**对手分 (Buchholz)**、**胜负分 (Sonneborn-Berger)**、**胜局数**、**黑白盘数**与**各轮对战明细**。
8. **数据安全与备份**：基于浏览器 `localStorage` 自动持久化保存，刷新页面不丢失；支持导出为 JSON 文件并在其他电脑或手机上导入恢复。

## ☁️ 部署到 Cloudflare Pages 指南

本项目为纯静态前端架构，**天然完美支持免费部署到 Cloudflare Pages**。部署后即可拥有公网访问域名（如 `https://simplechesspairing.pages.dev`），方便裁判长在赛场用手机、平板或电脑直接访问并完成比赛编排。

### 方式一：Wrangler 命令行一键部署（最快，仅需1分钟）
项目根目录下已配置好 `wrangler.toml`：
```bash
npx wrangler pages deploy . --project-name=simplechesspairing
```
首次执行会弹出浏览器授权 Cloudflare 账号，授权完成后终端会直接输出你的访问链接！

### 方式二：GitHub 自动化部署（推荐长期使用）
1. 将当前项目上传到你的 GitHub 仓库；
2. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，进入 **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**；
3. 选择你的项目仓库；
4. 构建设置：
   - **Framework preset**: `None`
   - **Build command**: 留空（无需构建命令）
   - **Build output directory**: `.`（当前目录）
5. 点击 **Save and Deploy**，10秒内即发布完成！后续只要 push 代码即可自动同步更新。

### 方式三：网页直接上传（无需 Git / 命令行）
1. 在 Cloudflare 控制台进入 **Pages** -> **Upload assets**；
2. 输入项目名（如 `simplechesspairing`），将整个文件夹拖入上传即可！

> 💡 **赛后录入比分与生成下一轮说明**：
> 部署后，所有瑞士制编排运算和比分录入都在裁判所持设备的浏览器本地执行，响应延迟为 0 毫秒。录入完成直接保存在该设备浏览器中，断网也可继续操作。

## 📖 操作流程与指南

### 1. 选择组别与开启比赛
- 点击顶栏右上方的 **【👦 男子组】** 或 **【👧 女子组】** 进行组别切换。
- 点击 **“👦 载入男子名单 (20人)”** 或 **“👧 载入女子名单 (7人)”** 即可自动填充选手名单。
- 点击 **“🚀 一键编排并开始第 1 轮”**，系统自动完成初赛分区配对。

### 2. 导出与打印带签字栏的对阵签单
- 点击顶部的 **“📑 导出签单”** 或在当前编排页点击 **“🖨️ 打印签单”**。
- 可下拉选择**任意历史轮次或当前轮次**。
- 可选择：
  - **手写空白签单**：赛果处留出 `[   ] : [   ]` 空白格，供赛前打印给选手，并在右侧白方、黑方签字栏亲笔签字；
  - **官方成绩存档**：显示已录入的最终比分，用于官方归档。
- 点击 **“🖨️ 打印签单 / 另存为 PDF”** 打印 A4 纸张；或点击 **“📥 导出 Excel (CSV)”** 下载表格文件。

### 3. 成绩录入与下一轮生成
- 每台比赛结束，裁判点击对应按钮录入比分：
  - `[ 1 - 0 ]`：白方胜
  - `[ ½ - ½ ]`：和棋
  - `[ 0 - 1 ]`：黑方胜
- 录入完成后点击底部的 **“🏁 结束本轮，生成下一轮编排”**，系统根据最新排名与瑞士制规则自动生成下一轮配对。

### 4. 中途增加新选手（0分入场）与请假
- 任意轮次点击 **“➕ 中途加人”** 输入姓名，即以 0 分入场参与下轮配对；
- 选手临时有事，点击 **“⏸️ 请假名单”** 设置为请假，下轮自动跳过该选手，已有积分保留不变。
